# sdt schema

> Generated by `sdt` dev. Regenerate with `sdt context docs`.

## Usage

```
sdt schema [flags]
```

## Description

Generate JSON Schema for SDT commands

Generate JSON Schema documents describing SDT command inputs and flags.

Without --command, emits a schema for every command as a JSON array.
With --command, emits the schema for a single command.

Examples:
  sdt schema                          # all commands
  sdt schema --command "jwt parse"    # single command
  sdt schema --format yaml            # YAML output

## Flags

| Flag | Shorthand | Type | Default | Description |
|---|---|---|---|---|
| `command` |  | string |  | Command path to generate schema for (e.g. "jwt parse") |

## Global Flags

| Flag | Type | Default | Description |
|---|---|---|---|
| `file` | string |  | Input File |
| `format` | string | text | Output format: text\|json\|yaml |
| `inb64` | bytesBase64 |  | Input Base 64 |
| `input` | string |  | Input String |
| `no-color` | bool |  | Disable ANSI color codes |
| `quiet` | bool |  | Suppress informational messages, only output result |

## Input / Output

- Input text: stdin | `--input` | `--file` | `--inb64` (in that precedence).
- Machine-readable output: `--format json` or `--format yaml`.
- Exit code `0` on success, `1` on error (message on stderr).
