## Global Conventions

- Input text: stdin | `--input` | `--file` | `--inb64` (in that precedence).
- Output: `--format text|json|yaml` (default text). Use `--format json`/`yaml` for machine-readable output.
- `--quiet` suppresses informational output; `--no-color` disables ANSI color codes.
- Exit code `0` on success, `1` on error (message on stderr).
- Paths are relative to the project root (e.g. `context/...`).
