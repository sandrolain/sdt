# SDT mind-map skill

Read the project's map instruction files before authoring or reviewing a map;
this skill routes to them and never restates them.

1. Read `context/instructions/mindmap.md` **before authoring any map** (the
   format-agnostic doctrine and the branch/node budgets).
2. Read `context/instructions/mindmap-markmap.md` for the markmap dialect, the
   `.map.md` document-management convention and its markers.
3. Respect the hard limit in the dialect: a map tool can only represent a
   hierarchy, not an arbitrary concept graph.

Verify the rendered map before claiming it is correct.
