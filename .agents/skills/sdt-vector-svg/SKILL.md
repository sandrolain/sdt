# SDT vector/SVG skill

Read the project's vector instruction files before drawing or optimising an SVG;
this skill routes to them and never restates them.

1. Read `context/instructions/vector.md` **before drawing anything** (the
   render-inspect-critique-fix doctrine).
2. Read `context/instructions/vector-svg.md` for the SVG markup contract:
   viewBox, accessibility, security, element ids and no hardcoded raster.
3. Read `context/instructions/vector-tools.md` to choose a render/verification
   tool.

Always render and inspect the artefact before claiming it looks right; a header
or comment is not evidence the drawing is correct.
